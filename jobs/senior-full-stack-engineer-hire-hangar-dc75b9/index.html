Job Title Senior Full Stack Engineer

Location Remote

Time Zone US Time Zones (PST - EST)

Role Overview

This is a high-ownership role for an engineer who is equally comfortable architecting backend automation pipelines and crafting polished, data-rich interfaces. You will work across the full stack, collaborating closely with AI/ML engineers, product managers, and UX designers to ship automation capabilities that are powerful, reliable, and intuitive to use.

Key Responsibilities

  • Architect and develop RPA agent pipelines integrated into our core SaaS platform
  • Build responsive, data-rich frontend interfaces that surface automation insights to end users
  • Design semantic context layers that give RPA agents the knowledge they need to make intelligent decisions
  • Collaborate with AI/ML engineers to integrate language models and decision engines into automation workflows
  • Contribute to the data platform layer — ingestion, transformation, and exposure via APIs and UI
  • Participate in design reviews, code reviews, and technical roadmap planning
  • Mentor mid-level engineers and help define engineering best practices

Required Qualifications

  • Senior-level full stack development experience (Node.js or Python backend; React or Vue frontend)
  • Proven experience building or integrating RPA solutions (UiPath, Automation Anywhere, Power Automate, or custom agent frameworks)
  • Familiarity with LLM integration patterns including RAG, tool-calling, and prompt engineering
  • Experience with semantic or knowledge graph layers, ontology-based systems, or structured context stores
  • Strong grasp of RESTful and event-driven API design
  • Exposure to cloud-native infrastructure (AWS, Azure, or GCP)
  • Must have prior remote work experience and be fluent with remote collaboration tools (Slack, Zoom, Google Workspace, or similar)

Preferred Qualifications

  • Experience with vector databases such as Pinecone, Weaviate, or pgvector
  • Background in agentic AI frameworks such as LangChain, AutoGen, or CrewAI
  • Familiarity with data pipeline tooling including dbt, Airflow, or Spark
  • Experience working in a B2B SaaS product environment

Tools & Technology

  • Python / Node.js
  • React / TypeScript
  • RPA platforms (UiPath, Power Automate, or similar)
  • Cloud platforms (AWS, Azure, or GCP)
  • Vector or graph databases
  • Slack, Zoom, Google Workspace

If your application is successful, you will receive an email confirming next steps. Applications that are not completed in full will not be considered for any open roles.
