Role Description This is a full-time remote role for a Website QA Specialist  in a growing U.S.-based company. The Construction Project Manager must have a strong eye for front-end detail, usability, responsiveness, and cross-browser functionality. This is not a traditional software QA role — we are specifically looking for someone with experience in website development and website testing.   Qualifications - ​​​​​​​3–5+ years of hands-on website QA or front-end QA experience - Deep familiarity with browser dev tools and debugging layouts, CSS, DOM structure - Experience testing across major devices (mobile, tablet, desktop) and browsers (Chrome, Firefox, Safari, Edge) - Understanding of accessibility (WCAG), Core Web Vitals, and SEO-related QA best practices - Comfortable working with design tools (e.g. Figma) to compare against actual builds - CMS familiarity (e.g. WordPress, HubSpot, Contentful, Webflow) is a plus - Experience with QA tools (e.g. BrowserStack, Percy, QA Wolf, or manual walkthroughs) Responsibilities - Test and validate website builds (including landing pages, CMS-driven sites, and marketing pages) - Identify layout issues, responsive bugs, and UI inconsistencies - Validate page behavior across modern browsers and devices - Ensure accessibility, usability, and performance best practices - Work closely with developers, designers, and PMs to clarify issues and ensure fixes - Document and track bugs using the team’s preferred tools (Jira, Trello, ClickUp, etc.) - Perform regression testing on new releases ​​​​ Compensation $ 2,500 - $ 3,500 per month, paid in USD depending on experience. Details - Independent contractor agreement paid 2x monthly. - Client has a desire for long-term commitment.
