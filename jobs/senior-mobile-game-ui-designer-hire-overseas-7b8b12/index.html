We're looking for a

Senior Mobile Game UI Designer with deep experience designing polished, commercially successful interfaces for casual, free-to-play mobile games. You will own the player-facing UI experience across core game screens, meta-progression, events, live ops, collection systems, shops, offers, rewards, onboarding, and social features.

This is not a role for someone who designs beautiful screens in isolation. Great mobile game UI is fast, readable, emotionally satisfying, monetization-aware, and ruthlessly optimized for player comprehension, retention, and conversion. If you have shipped successful mobile games, understand casual player behavior, and can design interfaces that feel premium while still supporting aggressive product goals, this role is a strong fit.

Why You'll Want to Join

You will be paid in USD (bi-monthly: every 15th and 30th)

Paid Time Off

in accordance with company policy

Observance of

Holidays per company guidelines

100% remote setup so you can work wherever you're most productive

This role requires availability during

US business hours

Own the full player-facing UI experience across a live mobile game with real commercial impact

Work in a fast-paced, metric-driven environment where designs are tested, measured, and improved continuously

What You'll Work On

UI Design and Player Experience

Own the visual and interaction design of key mobile game screens

Design UI driven by UX that is immediately understandable to casual players with strong hierarchy, clear calls to action, and minimal friction

Create high-polish mobile layouts that work across a wide range of screen sizes, aspect ratios, and device performance profiles

Balance usability, visual appeal, brand personality, and monetization goals without making the game feel cheap or overloaded

Product and Monetization Design

Design reward moments, upgrade moments, purchase flows, and progression feedback that feel satisfying, clear, and commercially effective

Understand how UI choices affect player behavior including button placement, reward framing, urgency, scarcity, value perception, and habit formation

Use data, A/B test results, player feedback, and competitive analysis to improve designs over time

Visual Systems and Execution

Develop and maintain scalable UI systems, components, layouts, iconography, and style guides

Create production-ready mockups, specs, flows, prototypes, and handoff documentation for engineering and art teams

Ensure final in-game UI matches the intended quality bar through implementation review, feedback, and iteration

Collaborate with motion designers or technical artists to define satisfying transitions, button feedback, reward reveals, pack openings, upgrade animations, and live ops presentation

AI-Driven Workflow

Build agent-driven workflows that combine human design judgment with AI-assisted output

Use generative AI tools to accelerate ideation, visual exploration, UI variation, icon concepts, moodboards, production support, and competitive analysis

Rapidly produce multiple visual directions and iterate based on team feedback, playtests, and product goals

What You Bring

5 or more years of professional UI design experience in games

3 or more years designing specifically for mobile free-to-play games

At least one shipped mobile game in a senior, lead, or major ownership capacity

Strong portfolio showing real mobile game UI work, not only marketing art or web and app design

Deep understanding of casual mobile UI patterns, monetization flows, progression systems, and live ops design

Strong visual design skills across layout, typography, color, hierarchy, iconography, composition, and polish

Excellent Figma skills including components, variants, libraries, and design systems

Experience designing for Unity-based mobile games or similar game engines

Ability to create clear flows, wireframes, prototypes, and production-ready screen specs

Strong communication skills with the ability to defend design decisions using player, product, and business reasoning

Comfortable working in a fast-paced, metric-driven production environment

Nice to Have

Experience on top-grossing casual, puzzle, social casino, sports, card collection, or tycoon games

Familiarity with Unity UI implementation constraints

Motion design experience for UI transitions, reward reveals, and monetization moments

Familiarity with tools such as Unity, Figma, After Effects, and AI-assisted creative tools

How to Apply

Please include

Your

updated resume

A portfolio link showing at least 4 to 6 examples of shipped mobile game UI work including screens, flows, or systems you owned

A short Loom video (1 to 2 minutes) introducing yourself, walking through one mobile game UI project you are proud of, and explaining the design decisions behind it and how it performed

Only candidates who submit both a portfolio and a Loom video will be moved to the next step of the hiring process.

If you design mobile game interfaces that are as commercially effective as they are visually polished and want to own the full player-facing UI experience on a live game, this role gives you the scope and the direct impact to do your best work.
