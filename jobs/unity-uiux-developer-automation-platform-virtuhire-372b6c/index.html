About the Role

We are seeking a talented and detail-oriented Unity UI/UX Developer to design and build a clean, responsive, and intuitive user interface for a real-time automation platform. This role focuses on transforming complex system data into easy-to-understand dashboards, alerts, and interactive experiences across WebGL, desktop, and mobile platforms .

The ideal candidate will have a strong background in

Unity development

, UI/UX design principles , and real-time data visualisation , with the ability to create polished, production-ready interfaces that enhance user decision-making and overall user experience.

REQUIREMENTS

Key Responsibilities

Design, develop, and implement high-performance user interfaces within Unity using Canvas, UI Toolkit, or hybrid approaches .

Build dynamic dashboards that display real-time data, notifications, and system insights.

Create intuitive user journeys and workflows for monitoring, controlling, and interacting with automated systems.

Optimise UI performance, responsiveness, and scalability across WebGL, desktop, and mobile environments.

Integrate front-end interfaces with external APIs and live data sources.

Collaborate closely with backend developers and automation teams to ensure accurate and seamless data presentation.

Develop and maintain modular, reusable UI components and scalable architecture.

Ensure interfaces are visually polished, user-friendly, and aligned with modern UX standards.

Required Skills & Experience

Strong experience developing applications in Unity (C#) with a primary focus on UI/UX development.

Proven experience building real-time, data-driven user interfaces.

Experience deploying applications across

WebGL, PC, and mobile platforms .

Solid understanding of UX principles, interaction design, and responsive layout systems.

Experience integrating APIs and handling live data streams.

Strong attention to detail with the ability to deliver polished, production-ready interfaces.

Excellent problem-solving skills and ability to work collaboratively within a multidisciplinary team.

Nice to Have

Experience implementing UI animations, transitions, and interactive feedback systems.

Previous experience developing dashboards, monitoring tools, control panels, or automation platforms.

Knowledge of performance optimisation techniques for UI-heavy applications.

Familiarity with design and prototyping tools such as

Figma

and Adobe XD .
