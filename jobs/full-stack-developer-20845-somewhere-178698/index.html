Full-Stack Software Engineer (.NET / C# / React) Employment Type: Full-time, Independent Contractor (Contract-to-hire or direct hire) Work Model: Remote (Exclusively sourcing from Latin America or South Africa) Work Hours: US Eastern Standard Time (EST) alignment (Shift runs ~8:00 AM – 5:00 PM ET/CT) Role Overview We are seeking a hands-on, mid-to-senior Full-Stack Software Engineer to add core capacity as we modernize our live software platform and build out AI-oriented features under new independent ownership. Working directly alongside the Lead Engineer, you will own features end-to-end across a Microsoft-centered stack. While this is a genuinely full-stack seat, the overwhelming majority of the work is C# backend engineering supported by SQL Server databases, an ASP.NET MVC and React/TypeScript front end, and Azure cloud infrastructure. Operating on an established production platform serving thousands of retailers and millions of consumers, you will bridge legacy platform modernization with high-value AI integration. Key Responsibilities 1. Backend Engineering & Data Architecture (Core Focus) - C# / .NET Development: Design, build, and maintain production-grade application logic and microservices using C# and ASP.NET Core / MVC. - Database Optimization: Write, debug, and optimize complex T-SQL queries, stored procedures, and schema changes against SQL Server to maintain high performance across a data-heavy platform. - Code Maintenance & Refactoring: Debug, optimize, and extend existing functionality within an established production codebase. 2. Front-End Development & Cloud DevOps - UI Construction: Develop responsive, clean user interface components using ASP.NET MVC alongside modern React and TypeScript. - Azure Administration: Deploy, monitor, and administer application infrastructure within Microsoft Azure, actively maintaining CI/CD deployment pipelines. 3. AI-Oriented Product Innovation - Feature Development: Contribute directly to AI-driven features, including personalization algorithms, smart recommendation logic, and LLM-powered functionality as the product roadmap evolves. - Pragmatic Implementation: Apply practical engineering judgment to evaluate where generative AI and machine learning deliver real, measurable user value versus technical complexity. Required Skills & Qualifications - Experience Level: Mid-to-senior level full-stack or backend engineering experience (no entry-level candidates). - Backend Mastery: Strong, demonstrable engineering skills in C# and .NET (ASP.NET Core / MVC)—this constitutes the primary focus of the role. - Database & Front-End Proficiency: Working proficiency with SQL Server/T-SQL, paired with hands-on experience building web application interfaces using React and TypeScript . - Cloud Infrastructure: Direct experience deploying, monitoring, and administering applications within Microsoft Azure using established CI/CD pipelines. - Communication & Overlap: Strong written and verbal English communication skills, with full availability during core U.S. business hours (EST/CST). Preferred Qualifications - Prior experience integrating AI/LLM tools, personalization frameworks, or recommendation engines into live SaaS platforms. - Technical background in loyalty programs, CRM platforms, retail tech, point-of-sale (POS), or payments . - Deep comfort navigating, maintaining, and modernizing established codebases (beyond greenfield development). - Experience operating effectively within small, agile, and lean engineering teams. Success Metrics (KPIs) - Feature Velocity & Quality: Consistently delivering clean, well-tested, and maintainable C# features to production on schedule. - Query & Platform Performance: Optimizing T-SQL queries and backend execution times to maintain high data integrity and low latency. - Deployment Reliability: Maintaining high CI/CD pipeline health and uptime across Azure-hosted application services.
