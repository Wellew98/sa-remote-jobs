What a Typical Day Looks Like

You might start by reviewing CI/CD test results and investigating a flaky Playwright test affecting the regression suite.

From there, you could build automated coverage for a newly released workflow, improve shared TypeScript fixtures, troubleshoot asynchronous behavior, or collaborate with an engineer on making a feature easier to test reliably.

You’ll also continuously improve test performance, framework stability, and automation coverage while experimenting with AI-assisted approaches to exploratory testing and edge-case detection.

you build the automation infrastructure that keeps software releases fast, reliable, and production-ready.
