Our client in the UK is seeking a highly capable full stack developer with strong expertise in the Microsoft technology stack along with PHP, HTML & CSS and specializing in building robust, scalable, and maintainable server-side and client-side applications and websites.

The ideal candidate should have good knowledge of SQL, create efficient API endpoints, whilst ensuring performance and reliability across complex systems. Skilled at navigating both modern .NET environments and undocumented legacy codebases, with a strong focus on clean architecture, debugging, and long-term maintainability. Knowledge of WordPress is also highly desirable.

Reporting to the IT & Development Manager, the successful candidate will work closely with the Projects Team to support the delivery of new opportunities and ongoing business changes across multiple functions and departments.

Core Technical Skills

VB.NET (Framework and .NET Core/6+)

Experience developing, maintaining, and refactoring backend systems using VB.NET across legacy and modern environments.

PHP

Experience developing, maintaining, and refactoring backend systems using PHP.

Front-End Skills (HTML, CSS, vanilla JS/JQuery)

Familiarity with UI structure and styling, enabling effective collaboration with other members of the front-end team.

Microsoft SQL Server (CRUD Operations)

Proficient in designing and maintaining SQL databases and performing optimized CRUD interactions.

RESTful API Development

Experienced in designing and implementing endpoints, integrating external services, and ensuring API reliability and security.

Debugging & Performance Profiling

Strong troubleshooting skills to identify and fix bottlenecks in .NET and SQL layers along with PHP scripts.

Desirable Skills

UX Understanding

Ability to assess and provide input on improving user flows and overall experience.

ASP.NET

Knowledge in creating server-side web applications, handling routing, middleware, and backend logic.

Experience of version control (GitHub/Azure DevOps)

Comfortable working with modern Git workflows, branching strategies, and CI/CD pipelines.

AI & Automation Technologies

Exposure to AI-focused tools and libraries (e.g., integrating LLM APIs for data classification or document processing).

Soft Skills

Legacy Code Adaptability

Adept at navigating, understanding, and improving undocumented or outdated codebases.

Strong Documentation Practices

Maintains clear, concise technical documentation to support team knowledge and long-term project stability.

Collaborative Work Style

Works effectively in team environments, especially during code reviews, design discussions, and version control processes. Contribution to our SCRUM meetings is expected.

Communication

Have good communication skills with the ability to help non-technical professionals understand requirements, issues, ideas etc.
