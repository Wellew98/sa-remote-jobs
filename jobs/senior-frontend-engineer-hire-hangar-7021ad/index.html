Job TitleSenior Frontend Engineer

LocationRemote

Time ZoneUS Time Zones (EST–PST)

Role Overview

We are seeking a Senior Frontend Engineer to build AI-powered product interfaces and analytics-driven user experiences. This role is ideal for someone who enjoys building highly interactive frontend applications using modern React architecture and AI integrations.

Key Responsibilities

  • Build and maintain frontend applications using React 19 and Next.js App Router
  • Develop dashboards and data-heavy interfaces
  • Translate designs into responsive production-ready UI
  • Build complex forms and scalable frontend components
  • Integrate AI-powered workflows and LLM functionality
  • Work with real-time frontend data flows
  • Optimize frontend performance and usability
  • Collaborate with product, design, and engineering teams remotely

Required Qualifications

  • Strong production experience with React 19 and Next.js App Router
  • Expert-level TypeScript strict mode experience (non-negotiable)
  • Strong Tailwind CSS implementation skills
  • Experience building dashboards, analytics tools, or data-heavy applications
  • Experience with Server Components and frontend state management
  • Production experience integrating LLM APIs into applications
  • Practical prompt engineering experience
  • Experience with OpenAI APIs or AI SDKs
  • Familiarity with AI-assisted development tools such as Cursor, Copilot, or Claude Code
  • Experience working with Supabase or similar BaaS platforms
  • Ability to work with PostgreSQL schemas and relational data structures
  • Experience implementing polling and real-time data-fetching patterns
  • Strong written and verbal English communication skills
  • Prior remote work experience, be fluent with remote collaboration tools and platforms (such as Slack, Zoom, Google Workspace, Jira, Linear, or similar), and have ideally worked with US or UK-based companies. Applications without this experience will not be considered.

Preferred Qualifications

  • Experience working on AI-native products
  • Familiarity with modern charting and visualization libraries
  • Experience contributing to design systems and scalable UI architecture

Tools & Technology

  • React 19
  • Next.js App Router
  • TypeScript
  • Tailwind CSS
  • Supabase
  • PostgreSQL
  • OpenAI API / AI SDKs
  • Cursor, Copilot, Claude Code
  • Google Workspace
  • Slack, Zoom, and other remote collaboration tools

Please NOTE

It is crucial that you complete the application form in full. As part of the application process, you will be required to record a video. If your application is successful, you will receive an email confirming next steps—the video is the first step of the interview process. If you do not record a video, we will not be able to consider you for ANY open roles.
