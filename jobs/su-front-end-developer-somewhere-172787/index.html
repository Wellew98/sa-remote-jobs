Role Description

This is a full-time remote role for a Front-End Developer at a growing US based company. The Front End Developer will be responsible for designing, developing, and implementing advanced features for web and mobile applications.

Qualifications

  • 2-3 years of professional experience working with front-end technologies such as JavaScript, React.js, React Native, or Ruby on Rails.
  • Proficiency in Python and modern web technologies.
  • Experience with performance optimization, offline storage, and multithreading techniques.
  • A bachelor’s degree in Computer Science, Engineering, or a related field, or equivalent practical experience.
  • Strong ability to collaborate and communicate effectively in a remote team setting.
  • Passionate about delivering high-quality, user-friendly applications.

Responsibilities

  • Design, develop, and implement advanced features for dynamic web and mobile applications.
  • Collaborate with cross-functional teams including product managers, UX/UI designers, and backend engineers to launch new features and improve existing platforms.
  • Integrate APIs and external data sources for seamless functionality.
  • Troubleshoot, identify, and resolve performance bottlenecks and bugs, ensuring exceptional application performance and user experience.
  • Stay up-to-date with the latest front-end technologies and apply innovative solutions to improve development processes.
  • Ensure that applications are responsive, high-quality, and optimized for speed and scalability.

Compensation

$2,000 - $6,000 per month, paid in USD depending on experience.

Details

  • Independent contractor agreement paid 2x monthly.
  • Client has a desire for long term commitment.
