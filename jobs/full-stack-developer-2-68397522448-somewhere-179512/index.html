Company Overview

A healthcare software company that builds technology for healthcare providers and medical equipment suppliers. The engineering team is adding developers for a separate product with its own codebase. We are hiring a Full-Stack Developer to help build and maintain that product.

Role Overview

You will join a small technical team building a healthcare software product, working across the .NET and C# backend, the Angular frontend, and the Microsoft SQL Server database. You will take features from requirements through to production and work closely with the product's development manager.

The stack is a traditional one, and we are looking for someone who writes clean, maintainable code and can work independently. You will also use AI-powered development tools day to day, while checking what they produce for security, accuracy, and maintainability.

Duties and Responsibilities

  • Design, build, test, and maintain features for a healthcare software product.
  • Develop backend functionality, APIs, and services with .NET and C#.
  • Build frontend features and components in Angular.
  • Translate product requirements into reliable, production-ready software.
  • Write clean, maintainable, well-structured code.
  • Write efficient Transact-SQL (T-SQL) for Microsoft SQL Server and use Entity Framework to connect the application to the database.
  • Design and maintain queries, tables, and data logic that support healthcare and durable medical equipment (DME) workflows.
  • Troubleshoot and optimize existing application components, including data and performance issues.
  • Use AI-powered development tools to speed up coding, debugging, testing, and documentation, and review their output for security, accuracy, and maintainability.
  • Work closely with the product's development manager and other developers through code reviews, testing, debugging, and documentation.
  • Communicate technical challenges, tradeoffs, and recommendations clearly.
  • Take ownership of assigned features from development through production.

Minimum Qualifications

Experience: 2 to 5 years of professional software development or full-stack development experience.

  • Strong hands-on experience with .NET and C#.
  • Experience with Microsoft SQL Server and Transact-SQL (T-SQL).
  • Experience with Entity Framework.
  • Experience building frontend applications with Angular.
  • Experience building backend services and APIs for production web applications.
  • Experience with Git and collaborative development workflows.
  • Strong debugging and problem-solving skills.
  • Strong written and spoken English communication skills.
  • Ability to work independently while collaborating closely with a small technical team.
  • Reliable high-speed internet connection and a fully equipped remote workstation.
  • Availability to work full-time, 40 hours per week, Monday to Friday, during U.S. Central Time business hours.
  • Flexibility to work an extra hour now and then when the team needs it.

Preferred Qualifications

  • Experience using AI coding assistants or AI agents in development work.
  • Experience with Microsoft Azure.
  • Healthcare technology experience.
  • Experience in the durable medical equipment (DME) industry or with DME workflows.
  • Experience working on an established product with an existing codebase.
