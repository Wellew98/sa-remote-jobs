IT Systems, Data & Automation Specialist

Employment Type:  Full time, independent contractor

Work Model:  Remote

Work Hours:  US work hours

Role Overview

This role supports daily IT operations while advancing workflow automation and system integrations across the organization. Think: Process Optimization by using System Automations. The ideal candidate has a knack for identifying inefficiencies and developing creative solutions.

Core Responsibilities (Prioritized)

1. APIs, Integrations & AI

  • Explore, create and implement API-based integrations and automation opportunities
  • Example: Quoting in CRM to Sales Order Execution in ERP
  • Lead workflow improvements involving:
  • ERP: Global Shop Solutions (Pervasive SQL/Actian Zen/Visual Basic)
  • CRM: HubSpot (Standard HTTP protocols and JSON)
  • Microsoft Suite
  • Assist with AI-enabled tools and use cases that improve efficiency, reporting, or decision-making
  • Lead the exploration of new AI tools becoming available

2. Microsoft 365 Enablement

  • Advance team adoption of Microsoft tools, especially SharePoint, Power Automate, Teams, and OneDrive
  • Improve internal workflows & communication methods through automation, standardization, and training
  • Create and maintain simple user documentation and SOPs to reduce support load

3. General Business IT Support

  • Provide insight into overall C3 system architecture & workflows, cybersecurity systems & policies, user device management, office hardware, IT projects, and more
  • Be a co-liaison and advisor between C3 Corporation and its managed service provider

Remote & International Expectations

Strong English fluency, overlap with U.S. Central Time, secure tool usage, documentation discipline, and video participation are required.

Qualifications (Requirements)

Broad IT experience, Microsoft 365 suite fluency, API development experience, experience working with American-based businesses / people

Preferences (Ideals)

Skills

  • CRM-ERP integration experience
  • SQL programming fluency

Characteristics

  • Observant
  • Creative
  • Self-driven
  • Eagerness to learn
  • Process oriented
  • Positive mindset
  • Personable
