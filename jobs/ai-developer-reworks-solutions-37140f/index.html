AI Full-Stack Developer

LocationRemote (South Africa Preferred)

Employment TypeFull-Time

About the Role

We're looking for an experienced AI Full-Stack Developer who thrives on building intelligent, polished, and practical business tools from the ground up.

This isn't a traditional developer role where you'll simply implement tickets. You'll own projects end-to-end—from designing data models and integrating multiple SaaS platforms to delivering intuitive, production-ready interfaces that people genuinely enjoy using.

The ideal candidate already uses AI-assisted coding tools like OpenAI Codex, Claude Code, Cursor, or similar as an essential part of their daily development workflow, helping them build faster while maintaining high-quality code

What You'll Be Doing

Design, build, and maintain full-stack web applications from concept to production.

Develop scalable applications using modern frameworks such as Next.js, React, Svelte, and Python.

Build internal business tools and operational dashboards that improve business efficiency.

Integrate third-party platforms using REST APIs, webhooks, authentication, and API keys.

Design clean, intuitive, and user-friendly interfaces with a strong focus on usability.

Own projects across the full development lifecycle—from architecture and backend logic to polished frontend delivery.

Collaborate with stakeholders to translate business problems into practical technical solutions.

Leverage AI-assisted development tools as a core part of your daily workflow to accelerate delivery without compromising quality.

Requirements

Technical Skills

3–5+ years of full-stack development experience.

Strong experience with

Next.js

React

Svelte

Python

Experience building and consuming REST APIs.

Practical experience working with

Webhooks

API keys

SaaS integrations

Strong understanding of application architecture, data modeling, and scalable development practices.

AI Development Experience

Hands-on experience using AI-assisted coding tools such as

OpenAI Codex

Claude Code

Cursor

GitHub Copilot

Similar AI development tools

AI-assisted development should be a regular part of your workflow—not occasional experimentation.

UX & Product Ownership

Demonstrated ability to create interfaces that are both functional and visually intuitive.

Strong understanding of UX principles and the reasoning behind good design decisions.

Experience building polished internal tools rather than solely consumer-facing applications.

Comfortable owning a product from planning through final implementation without relying on separate design handoffs.

What We're Looking For

We're looking for someone who is

A builder who enjoys solving real business problems.

Comfortable working independently and taking ownership.

Curious about AI and modern development workflows.

Detail-oriented with a strong eye for quality.

Able to balance speed with thoughtful engineering decisions.

Passionate about creating software that's enjoyable to use—not just functional
