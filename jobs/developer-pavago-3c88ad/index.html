TitleDeveloper

Top 3 Responsibilities: Build and ship features in the client portal (Next.js, TypeScript, PostgreSQL): lead tracking, call attribution, and client reporting. Take Stryker AI-native: build software factories, data factories, second brains, and agents that run fulfillment. Own integrations and production: Google Ads, Twilio, Zapier, the public API, deploys, migrations, monitoring, and incident write-ups.

Must Haves: Strong TypeScript and React (Next.js App Router). Solid SQL and PostgreSQL, including schema migrations. Has owned a production web app: deploys, live debugging, and security basics. Very comfortable with AI and agentic development: builds and ships with agents daily, not just autocomplete. Documents as they go: change logs, handoffs, and incident reports.

Nice to Haves: Drizzle ORM, Supabase, Vercel, or Clerk experience. Google Ads API, Local Services Ads, or call tracking (DNI) experience. Twilio voice and SMS, including A2P 10DLC. Testing: Vitest, Playwright, and k6 load testing. Has built agent systems: multi-agent pipelines, RAG/second brains, or LLM evals. Strong DevOps experience: CI/CD, infrastructure, and observability.

Disqualifiers: Serial job hoppers. Needs a full spec before starting any task. Has never carried production responsibility (deploys, incidents). Resistant to AI-assisted development.

Characteristics: Organized and documented. Core values: Competitive Greatness, Sincere Candor, Unimpeachable Character Self-directed in a remote, async environment. Bias to ship: small, verified changes over big rewrites.

Pitch: Reports directly to the Director of Automations/AI. Own features end to end - schema to UI to production - on a small, fast-moving team. AI-forward shop: agents handle the boilerplate, you do the engineering. Your code directly drives lead tracking and ad-spend decisions for real clients. Ground floor of taking the whole agency AI-native: you build the factories and the agents.

Logistics Reports to: Graham Thomson, Director of Automations/AI Direct reports: None currently Location: Remote Hours/Schedule: 9–5 EST - optional Salary: TBD Software: TypeScript, Next.js, React, Tailwind, PostgreSQL (Supabase), Drizzle ORM, Vercel, Clerk, Twilio, Google Ads API, Zapier, GitHub, Slack, Claude Code / AI coding agents
